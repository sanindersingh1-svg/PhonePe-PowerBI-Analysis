# PhonePe Payment Analytics Dashboard | Power BI

## 📊 Project Overview

This project presents an interactive **PhonePe Payment Analytics Dashboard** built using Microsoft Power BI. It analyzes transaction performance, payment success rates, user activity, service-wise transaction value, and usage patterns to provide a clear overview of digital payment operations.

The dashboard combines KPI cards, monthly trend analysis, user segmentation, service-level analysis, and transaction behavior visualizations in a PhonePe-inspired design.

## 🎯 Project Objectives

- Analyze overall transaction volume and transaction value.
- Monitor payment success rate.
- Understand unique user activity.
- Track monthly transaction trends.
- Compare transaction value across payment services.
- Identify top users by transaction value.
- Compare weekday and weekend usage patterns.
- Present key metrics in an interactive dashboard.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and visualization
- **DAX** — Measures and KPI calculations
- **Data Modeling** — Organizing transaction, user, and date data
- **Excel** — Source dataset

## 📌 Key Performance Indicators

The dashboard includes the following KPI cards:

| KPI | Description |
|---|---|
| Total Transactions | Total number of transactions |
| Total Value | Total transaction amount |
| Unique Users | Count of distinct users |
| Successful Rate | Percentage of successful transactions |

## 📈 Dashboard Features

### 1. Monthly Transaction Analysis
Tracks monthly transaction volume and transaction value to identify changes in payment activity over time.

### 2. User Segmentation
Visualizes user contribution by age segment to compare activity across different user groups.

### 3. Service Transaction Value Analysis
Compares transaction value across services such as loans, money transfers, insurance, and recharge bills.

### 4. Top 5 Users
Highlights the top five users based on transaction value.

### 5. Weekday vs. Weekend Usage
Compares payment activity across weekdays and weekends.

### 6. Interactive Filters
Includes Month and Payment Status filters to explore the dashboard from different perspectives.

### 7. Key Insights Panel
Provides a dedicated visual area for highlighting important business observations.
